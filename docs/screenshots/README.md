# Screenshot Assets

This directory is reserved for original, project-owned captures of the desktop
interface. The release-candidate documentation intentionally uses a textual placeholder
until suitable images are produced.

When adding a screenshot:

- capture only the Genesis Plus GX GUI interface and generated/public-domain test output;
- remove usernames, paths, controller serials, and other personal data;
- do not show commercial games, proprietary BIOS content, scraped box art, or Sega-owned
  artwork;
- use PNG with a descriptive lowercase filename; and
- record the application version, operating system, theme, DPI scale, and fixture
  provenance in this file.

After review, link the image from the root `README.md`. Screenshot files are documentation
assets, not emulator test goldens.
